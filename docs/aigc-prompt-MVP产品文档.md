# AIGC提示词站（aigc-prompt.com）· MVP 产品文档 v3

> 2026-10-08

---

## 一、定位

免费的**图片类**AI提示词展示站，瀑布流浏览，一键复制使用。不做文本类、不做视频类、不做交易。参考 Timi AI、PromptBase，不照搬内容。

---

## 二、内容来源

- 抓取提示词 + 效果图，**标注原作者 + 来源链接（小红书/抖音/X等）**
- 优先选可信度高、效果好的公开内容
- 提供"申诉/下架"联系方式，作者要求下架即时处理
- 第一版先集中做 1 个分类（**人像/头像**），50-100 条起步

---

## 三、分类（第一版）

- 头像/壁纸
- 人像写真
- 文案配图/海报
- 插画/壁纸
- Logo/品牌设计
- 美食/探店
- 场景/建筑

模型标签：即梦 / 可灵 / Midjourney / 豆包 / Stable Diffusion

---

## 四、MVP 功能点（只做这些）

1. **首页瀑布流**：卡片展示缩略效果图 + 标题
2. **分类筛选**：按场景分类
3. **详情页**：大图 + 完整提示词 + 适用模型 + 一键复制 + 来源标注（作者+原链接）
4. **搜索**：关键词搜标题

**不做**：登录、收藏、点赞、排序切换、相关推荐、平台内直接生成、用户上传、付费交易、视频类、多语言。

---

## 五、页面结构

```
首页
├─ 搜索框
├─ 分类筛选（横向标签）
└─ 瀑布流卡片（缩略图+标题）

详情页
├─ 大图
├─ 完整提示词 + 一键复制按钮
├─ 适用模型标签
└─ 来源标注（作者名 + 跳转链接）
```
