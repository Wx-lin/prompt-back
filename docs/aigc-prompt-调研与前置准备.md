## 二、决策过程与关键结论

### 2.1 为什么不做"交易市场"（否掉 PromptBase 模式）

调研了 PromptBase（海外头部提示词交易市场，33万+条提示词，覆盖 ChatGPT/Midjourney/DALL·E 等）后，确认该模式存在三个结构性问题：

1. **交易机制有先天漏洞**：买家付费解锁提示词原文后可直接复制转卖，平台无法有效保护交易资产。PromptBase 自身多年未能解决此问题，规模一直停留在"长尾小市场"量级，未能跃升为大生意。
2. **模型能力正在削弱该需求**：主流大模型（ChatGPT、Claude、国产模型）普遍内置"提示词优化/改写"能力，用户对"外部购买现成提示词"的依赖长期趋势是下降（但判断：窗口期仍有1-2年，尤其在非技术用户和国内市场）。
3. **国内付费习惯未建立**：国内现有同类站点（如 AIHub）均为免费导航/聚合形态，没有跑出规模化付费交易市场，说明国内用户对"付费买提示词"接受度低。

**结论**：放弃交易机制，改为**免费聚合展示**形态。

### 2.2 为什么选择"免费聚合广场"而非"填表式生成器"

原分析中曾提出三层递进方案：
- 层1：纯提示词交易市场（已否）
- 层2：填表式垂直生成器（卖结果不卖提示词原文，护城河更强）
- 层3：订阅制垂直模板库（持续更新驱动，运营成本高）

用户最终选择方向：**层0（新增）—— 免费提示词广场，不做交易，前期不考虑盈利**。

该选择的影响：
- 去除了"交易资产易被复制"的核心风险（内容本身即开放，无需防盗）
- 核心矛盾从"怎么防止被偷"转为"怎么获取流量、怎么留存"
- 变现方式延后考虑，可选路径包括：广告、引流至后续付费产品（如层2的生成器）、会员增值功能

### 2.3 关于"会不会有人用"的评估

**结论：会有人用，但属于"小而美、低频、强依赖持续运营"的产品形态，非"自增长"型产品。**

关键判断依据：
- AIGC 使用者总盘子大（国内千万级活跃用户），但存在漏斗效应：
  总用户 → 主动搜索提示词的比例（小）→ 搜索引擎/社交渠道能触达到本站的比例（更小）→ 形成回访习惯的比例（更小）
- 产品使用行为是"用一次就走"型（找到提示词→复制→去AI工具里用→离开），非高频打开型产品，天然日活/留存偏低
- 流量来源几乎全靠 **SEO + 社交渠道分享**（小红书、公众号、技术社群），非产品力自然增长
- 已有同类站点占据搜索结果前排位置多年（AIHub 等），新站起步需要持续内容运营才能获取流量

**对应策略**：接受"日活几百"为合理且现实的早期目标，产品定位为练手/内容资产积累型项目，不与大生意诉求绑定。

## 四、域名与命名

### 4.1 域名

- **最终确定：`aigc-prompt.com`**
- 决策过程：
  - 最初候选 `aigc-prompts.com`（复数形式），用户查询确认可注册
  - 后调整为单数形式 `aigc-prompt.com`，更简洁，用户已确认可注册
  - 曾提出面向国内用户的替代候选（`aiprompt.cn`、`promptku.com`、`tishici.com` 等拼音/中英混搭方案），因域名注册商网站存在反爬验证机制，未能通过自动化工具实时核验这些候选的注册状态
  - **用户最终选择维持 `aigc-prompt.com`**

### 4.2 中文名

- "AIGC" 的中文含义：**人工智能生成内容**（AI Generated Content），业内常用缩写，日常基本不翻译，直接使用英文缩写
- 候选中文名：
  1. **AIGC提示词**（与域名直接对应，零理解成本，推荐默认选项）
  2. AI提示词（认知门槛更低，覆盖更广泛的非技术用户，若想扩大受众可考虑此选项）
- **状态：待最终确认**（用户倾向于先推进域名定稿，中文名可在后续环节最终拍板）

## 六、风险提示（供后续决策参考，非当前结论的否定）

- **长期趋势风险**：随着大模型自身"理解模糊表达/自动优化提示词"能力增强，用户对"外部查找现成提示词"的依赖会逐步减弱，当前判断窗口期约 1-2 年，建议在此期间重点验证产品价值并视情况延伸至"卖结果"等更长期可持续的形态（如 MVP 验证后可考虑叠加前述"层2：填表式生成器"能力）。
- **流量获取风险**：免费聚合站的核心挑战是流量，而非技术实现，需要提前规划 SEO 策略和社交渠道分发动作（小红书、公众号、技术社群等），这是持续性运营投入，而非一次性开发投入。
- **备案与合规**：如使用国内服务器部署、面向国内用户，`.com` 域名在国内访问通常仍需 ICP 备案（具体以当时政策与托管方要求为准，建议动手前再次核实）。
