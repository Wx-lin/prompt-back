## 一、产品概述

| 项 | 内容 |
|---|---|
| 产品名称 | AIGC提示词（域名 aigc-prompt.com） |
| 产品形态 | Web 网页，瀑布流图片提示词展示站 |
| 一句话定位 | 国内用户也能用的、图片类AI提示词+真实效果图的免费画廊 |
| 目标用户 | 国内 AIGC 使用者：新手小白、自媒体/电商从业者、AI绘画爱好者 |
| 核心价值 | 不用自己摸索，直接抄一条验证过的提示词，看着效果图照着用 |
| 商业模式 | 前期不考虑盈利，优先验证产品形态和流量获取能力 |
| 成功标准 | 日活几百级别即视为 MVP 阶段达成目标 |

## 二、用户与场景

### 2.1 典型用户画像

| 画像 | 特征 | 核心需求 |
|---|---|---|
| 新手小白 | 刚开始用即梦/豆包，不知道怎么描述需求 | 抄一条现成的，改几个词就能用 |
| 自媒体/电商从业者 | 需要批量产出头像、封面图、产品图 | 高效找到对应场景的提示词，长期复用 |
| AI绘画爱好者 | 对效果有一定审美要求，愿意多尝试风格 | 浏览灵感、发现新风格、收集常用提示词 |

### 2.2 核心使用路径

```
产生需求（想要一张XX风格的图）
   ↓
搜索引擎/社交渠道搜到本站
   ↓
首页浏览 / 搜索 / 按分类筛选
   ↓
看到喜欢的效果图 → 点击卡片，弹出详情弹窗
   ↓
复制提示词 → 跳转到对应AI模型自己生成
   ↓
关闭弹窗，继续浏览（或在弹窗内看"更多相似"继续逛）
```

> **关键设计**：详情以**弹窗**形式呈现，不跳转新页面。用户关闭弹窗后，**浏览位置、滚动进度、当前筛选条件全部保留**，可以连续点开多张卡片快速浏览——这是与"跳转详情页"最大的体验差异，也是选择弹窗形态的核心理由。

### 3.2 详情弹窗（Modal）★ 核心交互

**功能描述**：点击首页卡片后，在**当前页面上方**弹出全屏遮罩的详情弹窗，不跳转页面。参考小红书网页版笔记详情。

**布局**：左右两栏。左侧大图区，右侧信息区（作者、操作、提示词、相似推荐）。

| 子功能 | 位置 | 详细说明 | 优先级 |
|---|---|---|---|
| 遮罩背景 | 全屏 | 半透明黑色遮罩覆盖底层页面，点击遮罩空白处关闭弹窗 | P0 |
| 关闭按钮 | 右上角 | "×" 图标，点击关闭弹窗 | P0 |
| **左侧大图区** | 左栏 | 展示完整效果图（非缩略图） | P0 |
| 图片切换 | 左栏 | 若一条内容有多张生成结果图，支持左右切换（缩略图指示器/小图列表） | P1 |
| 图片下载按钮 | 左栏右上 | 下载图标，支持保存图片 | P1 |
| **作者信息** | 右栏顶部 | 作者头像 + 昵称 + 账号/ID | P0 |
| 点赞/收藏/分享图标 | 右栏作者信息下方 | 图标+数字展示（收藏、点赞、分享），MVP阶段可只做展示不做实际功能 | P1 |
| **复制提示词按钮** | 右栏 | 核心操作，一键复制提示词到剪贴板，有明确"已复制✓"反馈 | P0 |
| **提示词文本区** | 右栏 | 展示完整提示词原文，长文本默认折叠，提供"展开更多"按钮 | P0 |
| 适用模型标注 | 右栏提示词上方 | 小字标注该提示词适用的模型（如"GPT Image 2"、"即梦"、"可灵"） | P0 |
| 翻译按钮 | 右栏提示词区右上 | 将英文提示词翻译成中文（可选功能，方便国内用户理解英文提示词） | P1 |
| **来源标注** | 右栏（作者信息区可点击） | 作者昵称可点击跳转到原始来源平台（小红书/抖音/X） | P0 |
| **更多相似** | 右栏下方 | 展示同分类/同风格的相似内容缩略图网格（2-3列小图），点击可切换到该内容的详情 | P1 |
| 举报/申诉入口 | 弹窗底部 | "内容有误或需要下架？联系我们"，提供下架申诉渠道 | P0 |
| 键盘操作 | 全局 | Esc 键关闭弹窗；左右方向键切换上/下一条内容（提升连续浏览效率） | P1 |
| 移动端适配 | 全局 | 移动端改为上下布局（上图下信息），或全屏单栏展示 | P0 |

## 五、非功能性需求

| 类别 | 要求 |
|---|---|
| 性能 | 图片懒加载 + CDN 加速；弹窗打开需即时响应，不产生明显等待 |
| SEO | 页面可被搜索引擎收录；**注意：详情在弹窗内，需额外为每条内容生成可被爬虫抓取的独立 URL**（技术上可用"弹窗+可直达URL"混合方案，如 `/prompt/123` 直接打开时以弹窗形式渲染在首页之上，兼顾SEO与体验） |
| 移动端适配 | 手机浏览器可访问；瀑布流 2 列；弹窗改为上下布局 |
| 合规 | 国内部署需 ICP 备案；提供内容下架申诉渠道 |

> **SEO 补充说明（重要）**：弹窗形态的常见代价是"内容无法被搜索引擎索引"（因为不产生独立URL）。解决方案是让每条内容同时存在一个可直达的 URL（如 `/prompt/123`），直接访问该 URL 时，以"首页+自动打开该弹窗"的方式呈现。这样既有弹窗的浏览体验，又不牺牲 SEO。这一点需要在技术选型阶段明确。

## 2026-10-13 范围扩展：用户发布作品

原“不做用户上传/UGC”范围由用户本次明确要求调整。登录用户通过主站发布入口上传作品图片、填写标题/提示词/说明/分类/具体模型版本，提交后进入人工审核；在“我的作品”查看待审、已公开、未通过（含理由）、已下架四种状态。运营后台“投稿审核”预览图片与完整内容，通过后公开，拒绝必须填写原因。用户不能自行设置审核/发布状态或冒用他人图片资产。未登录先登录，并安全回到原发布入口。

模型标签按家族分组、保留版本，同版本别名统一；支持为通用家族补充新版本。新版本通过后进入目录，不将不同版本的内容筛选结果混在一起。
